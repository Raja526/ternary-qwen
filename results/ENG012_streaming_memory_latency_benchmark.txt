Interpretation
--------------------------------------------------------------------------------
1. ENG010 and ENG011 use the same persistent packed selected-weight representation.
2. ENG011 changes temporary code decoding from a complete selected-matrix int8 decode to output-row-chunk decoding.
3. Streaming reduced mean timed-max process RSS by 6.490 MiB in these runs, while GNU maximum RSS was effectively unchanged.

5. These measurements apply to this model, three selected matrices, 22-token input, rows_per_chunk=64, CPU environment, and benchmark protocol.
