OBJECTIVE
---------

- group size

FROZEN PACKED FORMAT
--------------------
Encoding:

-1 -> 00
 0 -> 01
+1 -> 10
11 -> reserved

Four ternary values are stored per byte.

Group size:
128

Scales:
FP16 per-group reconstruction scales

Input:
FP16

Accumulation:
FP32

Output:
FP16


GPU003 IMPLEMENTATION
---------------------
The CUDA kernel directly reads:

1. FP16 activations
2. uint8 packed ternary codes
3. FP16 per-group scales

For each output element it:

1. identifies the batch/output row
2. reads packed bytes directly
3. extracts four 2-bit codes per byte
4. accumulates positive and negative activation contributions
5. applies the corresponding group scale
6. accumulates group contributions in FP32
7. converts the final result to FP16

The persistent packed representation is used directly.

GPU003 does not reconstruct a full FP16 weight matrix.

CONCLUSION
----------
GPU003 demonstrates that the frozen ENG001 2-bit packed ternary
representation can be consumed directly by a custom CUDA operator on
the NVIDIA Quadro P1000.

The CUDA implementation is bit-exact with the frozen OPT006 packed
CPU arithmetic for all GPU003 synthetic validation cases and for the
tested real frozen Qwen k_proj matrix/input sets.

This establishes correctness of the first packed-ternary CUDA compute
path.


LIMITATIONS / CLAIM DISCIPLINE
------------------------------
GPU003 is a correctness experiment.

No GPU performance benchmark was performed.

No GPU latency improvement is claimed.

No GPU throughput improvement is claimed.

No GPU memory advantage is claimed.

No whole-model GPU acceleration is claimed.

No full-model GPU integration was performed.

The kernel is intentionally correctness-oriented. One CUDA thread
currently computes an output element using serial inner accumulation.

Bit-exactness claims are specifically against the frozen OPT006 packed
CPU arithmetic for the tested GPU003 cases.

The 7.529412x compression value refers only to storage for the tested
selected packed weight relative to its FP16 equivalent. It is not a
whole-model compression claim.
